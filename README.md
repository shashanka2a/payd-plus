# Payd.plus - Next.js 15 App

A modern, production-ready Next.js 15 application with Tailwind CSS v3, SEO optimization, and Lucide icons.

## Features

- ⚡ Next.js 15 with App Router
- 🎨 Tailwind CSS v3 with custom theme
- 🔍 Comprehensive SEO meta tags
- 🎯 Lucide React icons
- ✨ GSAP animations
- 🌙 Dark mode support
- 📱 Fully responsive design

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm, yarn, or pnpm

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
